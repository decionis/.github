# .github

Organization-wide defaults and the public face of [github.com/decionis](https://github.com/decionis).

- [`profile/README.md`](profile/README.md) — the organization profile rendered on our GitHub homepage
- [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE) — default issue forms (bug report, feature request) for all public repositories
- [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) · [`CONTRIBUTING.md`](CONTRIBUTING.md) · [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) · [`SECURITY.md`](SECURITY.md) — community health defaults inherited by every Decionis repository that doesn't override them
